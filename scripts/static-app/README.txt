Infinite Canvas 静态包

1. 直接双击启动器：
   - Windows：infinite-canvas-launcher.exe 或 start.cmd
   - PowerShell：start.ps1
   - macOS / Linux：start.sh

2. 启动后会自动打开浏览器：
   http://127.0.0.1:3000

3. 常用参数：
   infinite-canvas-launcher --port 3210
   infinite-canvas-launcher --host 0.0.0.0 --port 3000
   infinite-canvas-launcher --no-open

4. 关闭方式：
   在启动器窗口按 Ctrl+C
